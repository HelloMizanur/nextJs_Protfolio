# 🚀 Professional Portfolio Website

This is my personal portfolio website designed to showcase my software development skills and projects[cite: 2]. It features a modern, responsive UI with a fully functional contact system[cite: 2].

## 🛠️ Built With

- **Framework:** [Next.js](https://nextjs.org/)[cite: 2]
- **Library:** [React.js](https://reactjs.org/)[cite: 2]
- **Animations:** [Framer Motion](https://www.framer.com/motion/)[cite: 2]
- **Email Service:** [EmailJS](https://www.emailjs.com/)[cite: 2]
- **Icons:** React Icons / Lucide React[cite: 2]

## 📧 Contact Integration

The contact form is integrated with **EmailJS**, allowing messages to be sent directly to my email address without a backend server[cite: 2].
